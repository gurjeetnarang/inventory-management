Notable Patterns & Gaps

Composables as global store useFilters / useAuth / useI18n use module-scoped refs (a singleton) instead of Vuex/Pinia — shared state without a store library.
Hand-rolled SVG charts Dashboard donut/bar charts are raw <svg> with stroke-dasharray math in computed properties — no charting library.
No database, no backend auth All data lives in memory (server/data/*.json loaded at import time). useAuth.js is a client-only mock; the API has no authentication layer.
Frontend/backend gap api.js calls /api/tasks and /api/purchase-orders, which don't exist in main.py. Tasks are actually merged client-side from mock user data in App.vue, so the missing calls fail silently via try/catch.
